Primera versión pública de **ModHub**, un gestor de mods universal para Windows.

## Descargas
- **ModHub-Setup.exe** — instalador (no necesita permisos de administrador; registra los enlaces `modhub://`).
- **ModHub-Portable.zip** — versión portable: descomprime y ejecuta `ModHub\ModHub.exe`. Guarda sus datos en la carpeta `Datos` de al lado.

No hace falta instalar Python.

## Qué hace
- Busca mods a la vez en Nexus Mods, CurseForge, Modrinth, Thunderstore, GameBanana, mod.io, AyakaMods y Mod DB.
- Detecta juegos de Steam, Epic, Xbox/Game Pass, GOG y portables.
- Instala con enlaces (hardlinks) y desinstala dejando el juego limpio.
- Filtros (contenido adulto, instalación automática, actualizados recientemente, categorías) y orden (populares, descargas, nuevos, actualizados).
- Instaladores FOMOD, imágenes de las webs y botón «Jugar».

Algunas webs (Nexus para descargar, CurseForge, mod.io) necesitan tu propia API key gratuita en Ajustes.

Windows puede mostrar un aviso de SmartScreen porque el programa no está firmado: «Más información» → «Ejecutar de todas formas».
